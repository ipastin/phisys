# Screen Map & Inventory

## 1. Screen inventory rules

Each Figma screen frame must include its ID in the frame name: `TOD-01 / Today / Default`.

Variants/state frames use suffixes:

```text
/ Default
/ Loading
/ Empty
/ Limited data
/ Stale
/ Error
/ Offline
/ AI unavailable
```

Not every screen needs every state; required states are defined in `12_STATE_MATRIX`.

## 14. Global overlays/sheets

These are patterns, not primary destination screens:

- time range selector;
- filter sheet;
- source/provenance sheet;
- chart point detail/crosshair;
- permission explanation sheet;
- destructive action confirmation;
- context inspector;
- sources/evidence sheet;
- edit structured candidate;
- share scope preview;
- snackbar/toast for non-critical confirmation.
