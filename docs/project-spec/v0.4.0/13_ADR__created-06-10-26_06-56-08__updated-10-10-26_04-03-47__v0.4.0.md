# Architecture Decision Record Index

## Status

Все перечисленные решения имеют status `Accepted` для specification v0.3.0. При изменении решения создаётся новый ADR/ссылка на superseding decision; история не переписывается молча.

**Accepted:** Canonical domain model independent of FHIR version.

## Change policy

Architecture-level change требует:

1. сформулировать проблему;
2. указать затронутые ADR/invariants;
3. минимум 2 alternatives + trade-offs;
4. accepted decision;
5. migration/compatibility impact;
6. eval/security impact;
7. update domain docs и `AGENTS.md` при необходимости.

Convenience implementation не является достаточной причиной silently нарушить accepted ADR.
